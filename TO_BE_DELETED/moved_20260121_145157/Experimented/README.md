# Experimented Folder

This folder contains experimental code that was developed but is no longer in active use.

## Files Moved Here

### API Routes
- `api/excel_execution_routes.py` - Excel-driven execution with UI instructions workflow
- `api/html_helper.py` - HTML parsing helper for element extraction

### UI Templates
- `web/templates/excel_execution.html` - UI page for Excel execution workflow

## What This Code Did

This was an experimental workflow that allowed:
1. Running Excel steps sequentially
2. Keeping browser open after Excel steps
3. Providing UI instructions dynamically
4. Executing instructions with Agent
5. Capturing XPaths automatically
6. Generating combined Excel file

## Why Moved

This experimental approach has been replaced with a new manual element registration utility approach. The code is preserved here for reference but is no longer integrated into the main application.
