📋 Overview

The HTML Parser has been massively enhanced with 10 new features to provide rich, self-healing, adaptive metadata that helps BOTH the AI Agent AND Playwright code generation.

Key Philosophy: Registry is a CACHE, Not a Requirement
  • ✅ Provides initial "hints" to speed up discovery
  • ✅ AI can still discover elements LIVE if HTML changes
  • ✅ Registry updates automatically with new discoveries
  • ❌ NOT hardcoded paths that break when HTML changes

🎯 What Was Implemented

1. Tab Extraction

Extracts ALL tabs with role="tab" and adds location context.

Benefit: AI distinguishes "Diagnosis tab" from "Diagnosis accordion"

2. Location Detection

Tags every element with semantic location: sidebar-filters, main-content, data-table-area, footer.

Benefit: AI can filter by location

3. Disambiguation

Adds semantic types: "tab-control" vs "filter-accordion"

Benefit: NO MORE CONFUSION!

4. Stability Scoring

Each element has 3-5 selector options, prioritized by stability (1-5).

Benefit: Automatic fallbacks

5. Table Structure

Extracts column headers, associated tabs, pagination controls.

Benefit: Table verification becomes automatic

6. Page Sections

Identifies major page sections for hierarchical structure.

Benefit: AI understands page layout

7. Playwright Hints

Adds behavioral hints: wait strategies, expected changes, verify selectors.

Benefit: Generated code knows what to wait for

8. Relationships

Maps tabs→panels, accordions→content.

Benefit: AI knows element relationships

9. Enhanced Naming

Names convey location and purpose: "Diagnosis accordion (sidebar)"

Benefit: Instantly clear context

10. Version 2.0

Registry format bumped to v2.0 with backward compatibility.

Benefit: Future-proof architecture

🔄 Self-Healing Architecture

❌ This is NOT Hardcoding!

Think of it like Google Maps:

  • HTML Parser = Satellite imagery (pre-mapping)
  • Registry = Saved locations database
  • AI Agent = Live GPS navigation
  • If a road changes: GPS recalculates route automatically! ✅

Scenario 1: Element EXISTS in Registry

AI Agent: "Find 'Diagnosis' tab in data-table"
  ↓
Registry: "Here's a hint: [role='tab']:has-text('Diagnosis')"
  ↓
AI tries registry selector FIRST
  ↓
✅ Works → Fast! No discovery needed

Scenario 2: Element NOT in Registry

AI Agent: "Find 'New Feature' button"
  ↓
Registry: "Never seen this before"
  ↓
AI discovers LIVE (like it does now)
  ↓
Saves to registry for next time
  ↓
✅ Registry grows automatically!

Scenario 3: HTML Changed

Playwright uses registry selector
  ↓
❌ Element not found
  ↓
Playwright falls back to AI discovery
  ↓
AI finds element with NEW selector
  ↓
Registry updates: selector "old" → "new"
  ↓
✅ Self-healing test!

🚀 How to Use the Parser

📌 Important: You DON'T need to run this manually!

The parser already ran for clinicalcommons.ccdi.cancer.gov and populated the registry with 352 elements.

The AI will use this automatically when you run test stories for that website.

When to Re-parse:

  • ✅ NEW website - To create initial element map
  • ✅ Major UI changes - To refresh the registry (optional, AI will still adapt)
  • ✅ Periodic updates - Every few weeks for optimization (optional)

SSH into EC2 and Run:

# 1. SSH into server
ssh -i ~/path/to/your-key.pem ubuntu@13.222.91.163

# 2. Navigate to project
cd ~/DATAHUB_AI_Agent

# 3. Activate virtual environment
source venv/bin/activate

# 4. Run parser for a website
python utils/fetch_and_parse_html.py https://YOUR_WEBSITE.com/path page_name

# Example:
python utils/fetch_and_parse_html.py https://example.com/explore home

View the Generated Registry:

# Pretty print the entire registry
cat element_maps/clinicalcommons.ccdi.cancer.gov/home_page.json | python3 -m json.tool | less

# Search for specific elements
cat element_maps/clinicalcommons.ccdi.cancer.gov/home_page.json | grep "Diagnosis"

# Count elements by type
cat element_maps/clinicalcommons.ccdi.cancer.gov/home_page.json | grep '"type"' | sort | uniq -c

Once the parser runs, the AI Agent will automatically use the registry when you run test stories. No additional configuration needed!
